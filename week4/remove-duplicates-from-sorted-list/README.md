# Remove Duplicates from Sorted List

## 1. Problem
Дан отсортированный односвязный список. Нужно удалить все дубликаты так, чтобы каждый элемент встречался в списке только один раз, и вернуть получившийся список.

## 2. Approach
Я использовал простой итеративный подход с одним указателем. Поскольку список уже отсортирован, все одинаковые элементы гарантированно стоят рядом друг с другом.

**Трудности и неудачные подходы:**
Сначала у меня была идея использовать структуру данных set (множество), чтобы сохранять туда уже встреченные значения. Если значение уже есть в сете, мы удаляем узел. Однако этот подход требует дополнительной памяти O(n), а главное — нарушает логику использования свойств отсортированного списка. Позже я понял, что раз список отсортирован, нам не нужно ничего запоминать: достаточно просто сравнивать текущий узел (current) со следующим (current.next).

**Трассировка примера (список: 1 -> 1 -> 2):**
1. current указывает на первый узел (1). Сравниваем current.val (1) и current.next.val (1). Они равны!
2. Переназначаем указатель: current.next = current.next.nex. Теперь список выглядит как 1 -> 2.
3. current остается на месте (1), снова сравниваем со следующим (2). Они разные, поэтому сдвигаем `current = current.next (теперь curren на 2).
4. У следующего элемента (current.next) значение None, цикл завершается. Возвращаем голову списка.

## 3. Time & Space Complexity
- **Time Complexity: O(n)**, где n — количество узлов в списке. Мы проходим по списку ровно один раз.
- **Space Complexity: O(1)**, так как мы не создаем новые структуры данных, а просто меняем указатели next у существующих узлов.

## 4. Reflection / Improvement
- **Is there a more efficient approach?** 
  Нет, O(n) по времени и O(1) по памяти — это предел для этой задачи, так как в любом случае нужно осмотреть каждый элемент хотя бы один раз.
