# Remove Linked List Elements

## 1. Problem
Дан односвязный список и число val. Нужно удалить все узлы списка, у которых значение равно val, и вернуть новую голову списка.

## 2. Approach
Я использовал фиктивный узел (dummy node), который указывает на реальную голову списка. Это очень сильно упрощает код.

**Трудности и неудачные подходы:**
Сначала я пытался решать задачу без dummy-узла, прямо с hea. Из-за этого возникала проблема: если удалять нужно было самый первый элемент (саму голову), то head смещался, и приходилось писать отдельный цикл или много условиif, чтобы обработать этот краевой случай. Код постоянно падал с ошибкой AttributeError, когда head становился пустым (None).
Создание фиктивного узла dummy перед началом списка полностью решило эту проблему: теперь удаление первого элемента ничем не отличается от удаления любого другого узла в середине или конце.

**Трассировка примера (список: 1 -> 2 -> 6 -> 3, val = 6):**
1. Создаем dummy -> 1 -> 2 -> 6 -> 3. current указывает на dummy.
2. Проверяем current.next (это 1, не равно 6) -> сдвигаем current на 1.
3. Проверяем следующий (2, не равно 6) -> сдвигаем current на 2.
4. Проверяем следующий (6, равно val) -> делаем current.next = current.next.next (теперь 2 ссылается на 3, минуя 6).
5. Проверяем следующий (3, не равно 6) -> сдвигаемcurrent на 3.
6. Цикл завершен. Возвращаем dummy.next.

## 3. Time & Space Complexity
- **Time Complexity: O(n)**, где n — количество узлов в списке. Мы проходим по списку один раз.
- **Space Complexity: O(1)**, так как используется только один дополнительный узел dummy и один указатель current.

## 4. Reflection / Improvement
- **Is there a more efficient approach?** 
  Это оптимальное итеративное решение. Также можно было бы решить задачу через рекурсию, но итеративный вариант безопаснее для памяти, так как не переполняет стек вызовов при очень длинных списках.
