# Palindrome Linked List

## 1. Problem
Дан односвязный список. Нужно проверить, является ли он палиндромом (читается одинаково слева направо и справа налево).

## 2. Approach
Я решил эту задачу в три этапа без использования дополнительной памяти под массивы: найти середину списка, развернуть вторую половину в обратную сторону и сравнить обе половины.

**Трудности и неудачные подходы:**
Самым первым решением было просто пройти по списку, выписать все значения в обычный Python-список (list), а потом проверить его на палиндром с помощью срезов (arr == arr[::-1]). Это решение работало отлично, но преподаватели и условие задач на связные списки обычно требуют пространственную сложность O(1). Мой первый подход тратил O(n) памяти на хранение массива значений.
Чтобы уложиться в O(1) по памяти, пришлось применить трюк: с помощью черепахи и зайца (slow и fast) найти середину списка, разворачивать вторую половину «на месте» с помощью изменения указателей next, а затем поэлементно сравнить начало и перевернутую вторую часть.

## 3. Time & Space Complexity
- **Time Complexity: O(n)**, где n — количество элементов в списке. Мы проходим по списку несколько раз (находим середину, разворачиваем и сравниваем), но все эти операции занимают линейное время.
- **Space Complexity: O(1)**, так как мы не выделяем дополнительную память под массивы или структуры данных, а работаем исключительно с указателями внутри самого списка.

## 4. Reflection / Improvement
- **Is there a more efficient approach?** 
  По времени O(n) и по памяти O(1) — это максимально эффективное решение. Улучшить сложность по времени невозможно, так как нам в любом случае нужно коснуться элементов списка, чтобы проверить их значения.
